Architecture

Engineered for modern PS5 hardware.

Every subsystem in Orbis is written from first principles in Rust and tightly integrated into the POLYMIRA console experience.

Shaders

RDNA2 → SPIR-V GPU-VS Translator

LLVM-verified gfx1013 ISA decoder with SSA fragment translation and automatic GPU vertex shader SPIR-V offload, dynamic GVBUF/GIBUF growth, and zero-copy indexed Vulkan draws.

Reliability

Live AUTO-HEAL Watchdog

Continuously monitors GPU submission latency and Vulkan device health. On VK_ERROR_DEVICE_LOST or stalls, Orbis tears down and rebuilds the renderer live without losing the session.

Memory & Tiling

PS5 Oberon SW_64KB Untiling

Bit-exact GFX10.3 SW_64KB_S and SW_64KB_R_X macro-tile untiling with XOR bank swizzling, mip-chain offset handling, 64 GiB coalescing Direct Memory pool, and 48-RT LRU cache.

Audio

AudioOut2 7.1 → Stereo Engine

Dedicated hardware-paced audio worker with 7.1-channel surround downmix to low-latency stereo output and clean synchronization with video presentation.

Storage

SaveData & LevelDB Persistence

Mounts per-title save directories inside POLYMIRA's data folder with automatic backup on unmount, stale lock cleanup, and crash-safe file flushing on window close.

Input & UX

DualSense, XInput & Borderless Fullscreen

Native ScePad controller mapping alongside keyboard & mouse bindings, borderless fullscreen console launch, and seamless PS5-style splash transitions from POLYMIRA OS.
