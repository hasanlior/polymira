Architecture

Engineered for modern PS5 hardware.

Every subsystem in Orbis is written from first principles in Rust and tightly integrated into the POLYMIRA console experience.

Shader JIT

RDNA2 → SPIR-V GPU-VS JIT

LLVM-verified gfx1013 ISA decoder with SSA fragment translation and automatic GPU vertex shader SPIR-V offload, dynamic GVBUF/GIBUF growth, and zero-copy indexed Vulkan draws.

Resilience

Live AUTO-HEAL Watchdog

Continuously monitors GPU submission latency and Vulkan device health. On VK_ERROR_DEVICE_LOST or queue stalls, Orbis tears down and rebuilds the renderer live without losing the session.

Upscaling & Pacing

FSR / DLSS & 2x/3x FrameGen

Integrated resolution upscaling with FSR and DLSS hooks paired with optional 2x and 3x Frame Generation passes to deliver smooth high-refresh output on desktop GPUs.

Diagnostics

Universal NID Telemetry

Instruments dynamic symbol resolution across every loaded PRX module, recording exact missing NIDs, call frequencies, and per-Title ID readiness metrics for rapid HLE bring-up.

Memory & Tiling

PS5 Oberon SW_64KB Untiling

Bit-exact GFX10.3 SW_64KB_S and SW_64KB_R_X macro-tile untiling with XOR bank swizzling, mip-chain offset handling, 64 GiB coalescing Direct Memory pool, and 48-RT LRU cache.

Audio, Saves & Input

AudioOut2, LevelDB & DualSense

Hardware-paced 7.1 → stereo audio worker, crash-safe per-title SaveData persistence with automatic backup on unmount, and native ScePad DualSense, XInput, and keyboard/mouse bindings.
