POLYMIRA Orbis

Our own experimental PS4 core.

Orbis is at an early stage and does not run commercial games yet. Use shadPS4 to play PS4 games today.

PS4 and PC share the x86-64 instruction set, so a game's own code can run directly on the PC. What has to be emulated is the system around it: the PS4 kernel and libraries for files, threads, memory, video, audio and controllers. Orbis loads a game's executable and connects each system call to its own implementation.

Orbis analysis

For a PS4 or PS5 game, open its options and choose Orbis analysis. Orbis reads the game's eboot.bin and lists the system libraries and functions it uses, with how many Orbis already implements. This shows exactly what has to be built for that game.

Try with Orbis

Try with Orbis loads and starts the executable and shows what it printed, including every system function it reached that is not implemented yet.

Self-test

Settings → Emulation Settings → POLYMIRA Orbis runs a small program built in the PS4 format: it prints a line through a PS4 system call, reaches one unimplemented function and exits normally.

Your files

Orbis runs only files you provide. It contains no Sony code, keys or firmware and cannot decrypt retail games; executables must be decrypted on your own console.

Roadmap

  1. Thread-local storage, memory and threads: PS4 homebrew reaches main.
  2. Video out, controllers, audio: homebrew samples run.
  3. GPU commands on Vulkan.
  4. Commercial games, one system library at a time.
