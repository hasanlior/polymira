POLYMIRA Orbis

Built-in clean-room Rust PS5 and PS4 emulation core.

See the ORBIS overview & Compatibility Database for live per-Title ID status (including Minecraft PS5 PPSA17221 In-Game) and architecture notes.

PS5, PS4, and PC share the x86-64 instruction set, allowing decrypted game code to run natively while POLYMIRA Orbis emulates the surrounding system: kernel services, memory management, HLE libraries, audio, input, and the Vulkan graphics pipeline.

Core subsystems

  • RDNA2 → SPIR-V GPU-VS JIT: LLVM-verified gfx1013 ISA decoder with SSA fragment translation and automatic GPU vertex shader SPIR-V offload.
  • Live AUTO-HEAL Watchdog: Monitors Vulkan device health and submission latency, rebuilding the renderer live on VK_ERROR_DEVICE_LOST or stalls.
  • FSR / DLSS & 2x/3x FrameGen: Integrated upscaling pipeline with optional 2x and 3x frame generation for high-refresh displays.
  • Universal NID Telemetry: Tracks dynamic symbol resolution and missing HLE NIDs per Title ID for rapid bring-up diagnostics.
  • PS5 Oberon Untiling: Bit-exact SW_64KB_S and SW_64KB_R_X macro-tile untiling with XOR bank swizzling and a 64 GiB Direct Memory pool.

Orbis analysis

For a PS4 or PS5 game, open its options and choose Orbis analysis. Orbis inspects the game's eboot.bin and reports the system libraries and NIDs it imports alongside current HLE coverage.

Try with Orbis

Try with Orbis boots the executable through the built-in Rust core, displaying live telemetry and any unimplemented NIDs reached during execution.

Self-test

Settings → Emulation Settings → POLYMIRA Orbis runs a minimal diagnostic binary verifying syscalls, HLE dispatch, and clean process teardown.

Your files

Orbis runs only files you provide. It contains no Sony code, keys, or firmware and cannot decrypt retail games; executables must be decrypted on your own console.
