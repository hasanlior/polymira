Apps and browser

YouTube, Twitch, streaming services and the built-in browser.

Apps that run inside the console

The built-in browser, YouTube (TV interface) and Twitch open inside POLYMIRA. Each app keeps its own login.

The app menu has back, forward, reload, start page, zoom and close. With a keyboard, F1 opens it.

Netflix, Disney+, Prime Video, Spotify

These services require Widevine DRM and a signed app binary. In builds that are not VMP-signed they open full screen in Microsoft Edge, with the in-game menu available on top. Choose the behaviour in Settings → Game Mode & System → Protected apps.

Adding apps

Use Apps → Add apps from the store, or the store's Apps tab. App icons are loaded from each service's own website.
