Game mode details

  • CPU priority: the game process runs at high priority.
  • Power plan: switches from Balanced or Power saver to High performance while you play. A performance plan you already use is left alone.
  • Close the Windows desktop: stops the taskbar and Explorer during play and starts them again afterwards. Open File Explorer windows close.

All of these are undone when the game ends, when you quit, and after a crash.
