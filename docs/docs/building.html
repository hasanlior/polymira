Building from source

Run and package POLYMIRA yourself.

Requirements: Windows 10 or 11 and Node.js 20 or newer.

npm install
npm run dev        # development
npm run typecheck  # type check
npm run dist       # installer and portable exe in release/

POLYMIRA is built with Electron (the castlabs build with Widevine), React and TypeScript. Every build places a POLYMIRA shortcut on the desktop; set NO_SHORTCUT=1 to skip it.

VMP signing

Streaming services require the app to be VMP-signed. Create a free castlabs EVS account once, then npm run dist signs the packaged app:

pip install --upgrade castlabs-evs
python -m castlabs_evs.account signup

Adding a platform or emulator

Edit src/shared/platforms.ts: add the emulator to EMULATORS (executable names and command line) and the platform to PLATFORMS (file types and runners). The interface and scanner pick it up automatically.
