Emulators

Downloading, configuring and choosing emulators.

Downloading

From the store's Emulators tab or Settings → Emulation Settings → Download emulators. Downloads come from each project's official releases and run in the background with progress, speed and time left in the top corner.

EmulatorSystems
RetroArch (with the cores your games need)NES, SNES, N64, Game Boy family, Sega, arcade and more
DuckStationPlayStation

Dolphin and Ryujinx have no stable download link; install them yourself and use Find emulators automatically.

BIOS and system files

Some systems need files from your own console: a PS1 or PS2 BIOS, PS3 system software, Switch keys, a Saturn BIOS. POLYMIRA does not provide them. Place them where the emulator expects them; the platform's note in the app says what is needed.

Controller setup

With Automatic controller setup in emulators on (the default), POLYMIRA writes controller settings before a game starts:

EmulatorSetup
DuckStation, PCSX2, Dolphin (GameCube), RPCS3Written by POLYMIRA the first time, then left alone
RetroArch, PPSSPP, Vita3K, shadPS4, xemu, Xenia, FlycastDetect controllers on their own
Cemu, Ryujinx, melonDS, AzaharSet up once in the emulator

If you change controls inside an emulator, POLYMIRA keeps your changes. Re-apply controller settings writes the defaults again.

Per-game settings

A game's options contain Emulator settings (this game): the emulator to use, a video filter for RetroArch games (CRT, LCD grid, sharp smoothing) and extra command line arguments.
