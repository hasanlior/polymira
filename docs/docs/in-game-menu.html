In-game menu

The menu you open on top of a running game.

While a game runs, press the controller's Guide button (or Back + Start, or Ctrl+Shift+Home). Which of these opens the menu is set in Settings → Controller Settings → In-game menu button.

ItemWhat it does
Resume gameCloses the menu and returns to the game.
Pause / Unpause gameSuspends the game process itself, independent of the emulator.
Take screenshotSaves the screen; screenshots are listed under Media → Screenshots.
Quick save / Quick loadSave and load a state in RetroArch games.
Return to home menuShows the POLYMIRA home screen with the game paused in the background.
Quit gameCloses the game and everything it started.

The performance panel shows the game's CPU and RAM use, system CPU and RAM, and GPU usage on NVIDIA cards.

Exclusive full screen

The menu draws over games running in borderless full screen. Games in exclusive full screen may hide it. Choose borderless or windowed full screen in the game's display settings.

While you play

POLYMIRA stays open behind the game on a black screen and stops its own animation, so it does not use GPU time. When the game exits, you are back on the home screen.
