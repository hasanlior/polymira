Installation

Download, install, update and uninstall.

Download

Get the latest version from GitHub Releases. Two files are published:

FileUse it when
POLYMIRA-Setup-x.y.z.exeYou want a normal install with a Start menu entry, a desktop shortcut and automatic updates.
POLYMIRA-Portable-x.y.z.exeYou want to run it without installing, for example from a USB drive.

SmartScreen warning

The installer is not code-signed yet, so Windows may show “Windows protected your PC”. Choose More info and then Run anyway.

Updates

The installed version checks GitHub Releases when it starts. A new version is downloaded in the background and verified against the SHA-256 digest GitHub publishes for the file. You get a notification when it is ready; install it from Settings → About → Install update. The app closes, installs and starts again.

Automatic checks can be turned off with Settings → About → Check for updates on start. After an update, Settings → About → What's new shows the release notes. Notes for every version are also on the changelog.

Where your data lives

Settings, the library, covers, screenshots and save backups are stored in %APPDATA%\POLYMIRA. Uninstalling the app keeps this folder; delete it yourself for a clean start.

Uninstall

Use Settings → Apps → Installed apps in Windows and remove POLYMIRA. Emulators downloaded by POLYMIRA live inside the data folder above.
