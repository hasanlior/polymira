Save data

Backups and restores for every emulator.

Settings → Save Data Management lists every configured emulator with the folders where it keeps saves and save states. POLYMIRA finds them in the emulator's portable folder or in Documents / AppData.

Backups

  • With Back up automatically after playing on, the emulator's saves are zipped when a play session ends.
  • The last 10 backups per emulator are kept.
  • Back up all saves now backs up every emulator at once.

Restore

Pick an emulator, Restore from backup, then a date. Your current saves are backed up before the restore, so it can always be undone.

Sync folder

Choose a folder inside OneDrive, Google Drive or on a USB drive. Every backup is copied there as well, and backups found there appear in the restore list on other PCs.

melonDS stores saves next to the game file; those .sav files are included in its backups.
