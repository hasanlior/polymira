Troubleshooting

Common problems and how to solve them.

Windows blocks the installer

Choose More info → Run anyway. The installer is not code-signed yet.

The in-game menu does not appear

Switch the game or emulator to borderless full screen. With a PlayStation controller, the PS button is not visible to Windows' Xbox controller interface: use Steam Input or DS4Windows, Back + Start, or Ctrl+Shift+Home.

“Emulator not set”

Download it from the store, or use Settings → Emulation Settings → Find emulators automatically or Scan emulator folder.

A game starts and closes immediately

The emulator is usually missing a BIOS or system files. Check the platform note in the app and the emulator's own documentation.

“RetroArch core missing”

Cores are downloaded with RetroArch. For other cores use RetroArch's Online Updater → Core Downloader.

A store game opens but play time is not counted

POLYMIRA finds the game's process from its install folder. Games added only as a .url shortcut have no folder to look in; add them through the PC scan instead.

Netflix opens in Edge

Expected in builds without a VMP signature. See Apps → Netflix.

The taskbar is missing after a crash

The watchdog restores it automatically. If it does not, press Ctrl+Shift+Esc, choose Run new task and start explorer.exe.

Start over

Quit POLYMIRA and delete %APPDATA%\POLYMIRA. The next start runs the welcome wizard again.

Report a problem

Open an issue on GitHub with your Windows version, the game's platform and what happened.
